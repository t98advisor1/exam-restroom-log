# 🚻 시험 중 화장실·보건실 출입 기록 (exam-restroom-log)

시험 감독 중 학생의 화장실(8곳)·보건실 출입 시각을 태블릿·휴대폰에서 원터치로 기록하는 웹앱입니다.
**현장용 화면**과 **고사본부 대시보드** 두 페이지로 나뉘며, 외부 라이브러리·서버·계정이 필요 없습니다.

| 화면 | 주소 | 쓰는 사람 · 하는 일 |
|---|---|---|
| 현장용 | https://t98advisor1.github.io/exam-restroom-log/ | 학생·복도감독 — 초성/학번으로 찾아 **입장**, 나올 때 **퇴장**, 감독교사 확인 |
| 고사본부 | https://t98advisor1.github.io/exam-restroom-log/dashboard.html | 고사본부 — 9곳 실시간 현황, 그래프, 전체 기록, CSV, 명렬표 설정, 데이터 파기 |

- 파일: `index.html`, `dashboard.html`, `core.js`(공용 데이터 계층), `app.css` — 정적 파일만 사용
- 저장: 기록은 **그 기기의 브라우저 저장소(localStorage)** 에만 저장되며 서버로 전송되지 않습니다.
  두 페이지는 같은 저장소 키(`examRestroom.*`)를 쓰므로 **같은 기기에서 함께 열면 1~2초 안에 서로 갱신**됩니다.

## 위치 9곳 (주소로 바로 열기)

| 위치 | 주소 파라미터 |
|---|---|
| 1층 남 / 여 | `?zone=1M` · `?zone=1F` |
| 2층 남 / 여 | `?zone=2M` · `?zone=2F` |
| 3층 남 / 여 | `?zone=3M` · `?zone=3F` |
| 4층 남 / 여 | `?zone=4M` · `?zone=4F` |
| 보건실 | `?zone=NURSE` |

`&lock=1`을 붙이면 위치가 잠긴 상태로 열립니다(예: `?zone=3F&lock=1`).
현장 화면 상단 `🔓 위치 잠금` 버튼으로 현장에서 잠그고 풀 수 있습니다.

## 현장용 화면 (`index.html`)

1. 상단 **위치 배지**(`📍 2층 남`)를 눌러 위치 선택 → `🔒 위치 잠금`
2. 학생 입력창에 **초성**(`ㅎㄱ`) 또는 **학번**(`203`)을 입력 — 입력 전에는 명렬표를 나열하지 않고,
   1글자 이상 입력했을 때만 후보(이름 + 학번)가 드롭다운으로 나타납니다
3. 후보를 탭 → **`[입장]`** → 현재 시각이 자동 기록되고 `이용 중` 목록에 카드 생성
4. 학생이 나오면 카드의 **`[퇴장]`** 원터치 → 체류시간 자동 계산
5. 퇴장한 기록은 아래 **`📝 감독교사 확인`** 에 최근 순으로 표시 → **`[감독교사 확인]`**(또는 `모두 확인`)

표시되는 경고

- `⚠️ 동시 체류` — 같은 화장실에 2명 이상 겹칠 때 (상단 배너 + 카드 배지)
- `⏱ 5분 이상` — 체류 5분 초과 시 시간 강조
- **보건실**은 부정행위 감시 대상이 아니므로 동시 체류 경고에서 제외하고 일반 이용으로 표시합니다.

## 고사본부 대시보드 (`dashboard.html`)

- 전체 현황: 총 이용 건수 / 현재 이용 중 / **동시 겹침 쌍(화장실 기준)** / 평균 체류시간
- 그래프: **시간대별 입장 건수**, **장소별(1~4층 + 보건실) 이용 건수**
- 화장실별 현황 카드 9개 — 카드를 누르면 아래 기록이 그 장소로 좁혀집니다
- 전체 출입 기록: 장소·상태 필터(전체 / 확인 필요 / 5분 이상 / 동시 겹침), `[전체 감독교사 확인]`, `[⬇ CSV]`, 행별 확인·삭제
- `⚙️ 설정 · 명렬표` — 시험명, 명렬표 붙여넣기·CSV 파일·구글 시트 URL 불러오기
- `🗑 데이터 파기` — 2단계 확인, 파기 전 CSV 내려받기, 명렬표까지 삭제 선택

## 명렬표 바꾸기

`⚙️ 설정 · 명렬표`(대시보드)에서

- 구글 시트·엑셀의 `학년 / 반 / 번호 / 이름` 열을 복사해 붙여넣기 (탭·쉼표·공백 구분 인식)
- `20315 홍길동`처럼 학번+이름 한 줄 형식도 인식
- CSV 파일 선택
- 구글 시트 주소로 바로 불러오기 (`[파일 → 공유 → 웹에 게시]` 후 CSV 권장. 보안 정책상 막히면 붙여넣기 사용)

기본 내장 명렬표는 테스트용 가상 45명(동명이인 포함)입니다.

## 기기 간 동기화

이 앱은 서버가 없어 **다른 기기의 기록은 자동으로 모이지 않습니다.**
화장실 태블릿 8대를 쓴다면 각 기기에서 `[⬇ CSV]`로 받아 취합하거나,
추후 구글 시트(Apps Script) 연동을 붙이면 9개 기기 기록이 고사본부 대시보드로 실시간 집계됩니다.
