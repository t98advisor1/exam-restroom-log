# 🚻 시험 중 화장실·보건실 출입 기록 (sch-exam)

시험 감독 중 학생의 화장실(8곳)·보건실 출입 시각을 태블릿·휴대폰에서 원터치로 기록하는 웹앱입니다.
**현장용 화면**과 **고사본부 대시보드** 두 페이지로 나뉘고, 기록은 **구글 시트와 실시간 동기화**됩니다.

| 화면 | 주소 | 쓰는 사람 · 하는 일 |
|---|---|---|
| 현장용 | https://sch-exam.vercel.app/ | 학생·복도감독 — 초성/학번으로 찾아 **입장**, 나올 때 **퇴장**, 감독교사 확인 |
| 고사본부 | https://sch-exam.vercel.app/dashboard.html | 고사본부 — 9곳 실시간 현황, 그래프, 전체 기록, CSV, 명렬표·API 설정, 데이터 파기 |

- 파일: `index.html`, `dashboard.html`, `core.js`(공용 데이터 계층), `app.css` — 정적 파일만 사용 (Vercel 배포)
- 서버 코드: `Code.gs` — Google Apps Script 웹앱(구글 시트 읽기/쓰기). **학생 명렬표·출입기록은 시트에만 있고 이 저장소에는 없습니다.**

## 데이터 흐름

```
태블릿 9대  ──(2~3초 폴링 / 쓰기 즉시 전송)──▶  Apps Script 웹앱(Code.gs)  ──▶  구글 시트
                                              ├ '명렬표'   (학번·이름·학년·반·번호)
고사본부 대시보드 ─────────────────────────▶  └ '출입기록' (id·학번·이름·학년·반·위치·입장·퇴장·상태·감독확인·확인시각·동시체류)
```

- 어떤 기기에서 입장·퇴장·확인하면 **시트에 즉시 기록**되고, 다른 태블릿과 대시보드에 **2~3초 안에** 반영됩니다.
- 쓰기는 `LockService` 스크립트 잠금 안에서 처리해 여러 태블릿이 동시에 눌러도 기록이 겹치거나 유실되지 않습니다.
- 기록 id는 화면에서 만들어 보내므로, 응답이 유실돼 재전송해도 **중복이 생기지 않습니다**(실패 시 최대 5회 자동 재전송).
- 동기화가 끊기면 상단 배지가 `🔴 동기화 오류 — 재시도 중` 으로 바뀌고, 복구되면 자동으로 다시 맞춰집니다.
- API 주소를 비우면 예전처럼 **그 기기의 브라우저 저장소만** 사용하는 모드로 동작합니다.

## 위치 9곳 (주소로 바로 열기)

| 위치 | 주소 파라미터 |
|---|---|
| 1층 남 / 여 | `?zone=1M` · `?zone=1F` |
| 2층 남 / 여 | `?zone=2M` · `?zone=2F` |
| 3층 남 / 여 | `?zone=3M` · `?zone=3F` |
| 4층 남 / 여 | `?zone=4M` · `?zone=4F` |
| 보건실 | `?zone=NURSE` |

`&lock=1`을 붙이면 위치가 잠긴 상태로 열립니다(예: `?zone=3F&lock=1`).
현장 화면 상단 `🔓 위치 잠금` 버튼으로 현장에서 잠그고 풀 수 있습니다.

## 현장용 화면 (`index.html`)

1. 상단 **위치 배지**(`📍 2층 남`)를 눌러 위치 선택 → `🔒 위치 잠금`
2. 학생 입력창에 **초성**(`ㅎㄱ`) 또는 **학번**(`10105`)을 입력 — 입력 전에는 명렬표를 나열하지 않고,
   1글자 이상 입력했을 때만 후보(이름 + 학번)가 드롭다운으로 나타납니다
3. 후보를 탭 → **`[입장]`** → 현재 시각이 자동 기록되고 `이용 중` 목록에 카드 생성
4. 학생이 나오면 카드의 **`[퇴장]`** 원터치 → 체류시간 자동 계산
5. 퇴장한 기록은 아래 **`📝 감독교사 확인`** 에 최근 순으로 표시 → **`[감독교사 확인]`**(또는 `모두 확인`)

표시되는 경고

- `⚠️ 동시 체류` — 같은 화장실에 2명 이상 겹칠 때 (상단 배너 + 카드 배지, 상대 이름 표시)
- `⏱ 5분 이상` — 체류 5분 초과 시 시간 강조
- **보건실**은 부정행위 감시 대상이 아니므로 동시 체류 경고에서 제외하고 일반 이용으로 표시합니다.

## 고사본부 대시보드 (`dashboard.html`)

- 전체 현황: 총 이용 건수 / 현재 이용 중 / **동시 겹침 쌍(화장실 기준)** / 평균 체류시간
- 그래프: **시간대별 입장 건수**, **장소별(1~4층 + 보건실) 이용 건수**
- 화장실별 현황 카드 9개 — 카드를 누르면 아래 기록이 그 장소로 좁혀집니다
- 전체 출입 기록: 장소·상태 필터(전체 / 확인 필요 / 5분 이상 / 동시 겹침), `[전체 감독교사 확인]`, `[⬇ CSV]`, 행별 확인·삭제
- `⚙️ 설정` — 시험명, **실시간 동기화 API 주소(연결 확인·해제)**
- `🗑 데이터 파기` — 2단계 확인, 파기 전 CSV 내려받기. 동기화 중에는 **시트의 출입기록만** 지우고 명렬표는 남깁니다.

## 참고

- 명렬표는 **API를 통해서만** 불러옵니다. 저장소·정적 파일에는 학생 이름이 하드코딩되어 있지 않습니다.
- 기본 내장 명렬표(테스트용 가상 46명)는 동기화가 연결되지 않았을 때만 쓰입니다.
- 시험이 끝나면 대시보드 `🗑 데이터 파기` 로 시트 기록을 지웁니다(개인정보 최소 보관).
