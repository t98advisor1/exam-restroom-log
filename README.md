# 🚻 시험 중 화장실 출입 기록 (exam-restroom-log)

시험 감독 중 학생의 화장실 출입(입실·퇴실) 시각을 태블릿·노트북·휴대폰에서 원터치로 기록하고,
동시 체류·장시간 체류를 표시하는 단일 페이지 웹앱입니다. 설치 없이 브라우저로 열면 바로 쓸 수 있습니다.

- 라이브: https://t98advisor1.github.io/exam-restroom-log/
- 파일: `index.html` 하나 (외부 라이브러리·서버·계정 없음)
- 저장: 기록은 그 기기의 브라우저 저장소(localStorage)에만 저장되며 서버로 전송되지 않습니다. 기기끼리 자동 동기화는 없습니다.

## 위치 고정 (화장실 8곳)

주소 뒤에 `?zone=`을 붙이면 그 화장실로 바로 열립니다.

| 위치 | 주소 |
|---|---|
| 1층 남 | `?zone=1M` |
| 1층 여 | `?zone=1F` |
| 2층 남 | `?zone=2M` |
| 2층 여 | `?zone=2F` |
| 3층 남 | `?zone=3M` |
| 3층 여 | `?zone=3F` |
| 4층 남 | `?zone=4M` |
| 4층 여 | `?zone=4F` |

`&lock=1`을 붙이면 위치가 잠긴 상태로 열립니다(예: `?zone=3F&lock=1`).
상단 `🔓 위치 잠금` 버튼으로 현장에서 잠그고 풀 수 있습니다.

## 사용 순서

1. 학생 검색 — 초성(`ㅎㄱ`), 이름 일부(`길동`), 학번(`20315`)으로 찾고 후보를 탭
2. `[입실]` — 입실 시각이 기록되고 `현재 이용 중`에 카드가 생김
3. 나올 때 카드의 `[퇴실]` — 퇴실 시각과 체류시간 자동 계산
4. 기록 행의 `[감독교사 확인]` — 확인 시각과 함께 `확인 완료` 배지 (`전체 감독교사 확인`도 있음)
5. 시험 종료 후 `[⬇ CSV 내려받기]` → `[🗑 데이터 파기]` (2단계 확인)

## 명렬표 바꾸기

`⚙️ 설정 · 명렬표`에서

- 구글 시트·엑셀의 `학년 / 반 / 번호 / 이름` 열을 복사해 붙여넣기 (탭·쉼표·공백 구분 모두 인식)
- `20315 홍길동`처럼 학번+이름 한 줄 형식도 인식
- CSV 파일 선택
- 구글 시트 주소로 바로 불러오기 (`[파일 → 공유 → 웹에 게시]` 후 CSV 사용 권장, 보안 정책상 막히면 붙여넣기 사용)

기본 내장 명렬표는 테스트용 가상 45명(동명이인 포함)입니다.

## 표시되는 경고

- `⚠️ 동시 체류` — 같은 화장실에 2명 이상이 겹칠 때 (상단 배너 + 카드 + 기록 배지)
- `⏱ 5분 이상` — 체류 5분 초과 시 시간 강조
- 상단 요약: 총 이용 건수 / 현재 이용 중 / 동시 겹침 쌍 / 평균 체류시간 + 시간대별·층별 막대 그래프
